AICORD BRAND BUNDLE
===================
Colors: Blurple #5865F2 | Cyan #22D3EE | Indigo #1B1B4B | Midnight #0B1020
Font: Inter (ExtraBold headings, SemiBold labels, Regular body)

FOLDERS
01-logo          Logos in SVG + PNG + WebP.
                   for-dark-bg  = white "Cord" text, use on dark backgrounds
                   for-light-bg = dark "Cord" text, use on light backgrounds
                   (transparent files look empty on the wrong background)
02-favicon       favicon.ico, favicon.svg, PNG sizes, apple-touch-icon, android icons,
                 maskable icon, site.webmanifest, html-head-snippet.txt
03-discord       Bot avatar, bot banner, server icon/banner, invite splash, embed icons, emoji
04-email         Email headers dark/light (PNG + JPG), signature logos, footer icon
05-social        OG image, Twitter/X header, YouTube banner, GitHub preview, LinkedIn banner
06-brand-guide   One-page brand guide
07-social-media  Profile pictures, banners, stories, highlight covers and bios for
                 YouTube, Instagram, X, Threads, TikTok, WhatsApp, Facebook, LinkedIn,
                 Telegram, Reddit, Twitch, Pinterest, Bluesky, Mastodon, GitHub,
                 Product Hunt and Patreon. Start with _all-profile-pictures and _all-banners.
by-format        All SVG files and all WebP files, flat

Replace YOUR-DOMAIN / YOUR-LINK in the snippet and bio files with your real links.
