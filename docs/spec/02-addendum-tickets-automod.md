# Discord Architect - Addendum 2: Tickets, Automod, MEE6/Carl-bot Style Features

## COMMAND STRUCTURE
Discord allows only 100 global chat-input slash commands, and modals allow max 5 inputs.
- Group everything under top-level commands with subcommands/subcommand groups: /ticket, /role, /channel, /mod, /level, /birthday, /giveaway, /automod, /config, /tag, /timer, /embed, /invite, /ai, /backup, /economy, /utility.
- Keep a central command registry file that generates definitions, handlers, and docs pages from one source of truth.
- Use autocomplete, buttons, select menus, and modals instead of long option lists.

## 1. ADVANCED TICKET SYSTEM (Ticket Tool / Sapphire style)
- Multiple PANELS per guild, each with its own: embed, button or select-menu layout, target category, support roles, ping roles, naming scheme, max open tickets per user, welcome message template, and optional required roles.
- Pre-ticket FORMS via modal (up to 5 questions per type, short/paragraph, required flag). Answers posted in ticket channel as embed.
- Ticket actions: Claim/Unclaim, Close (with optional reason and confirmation), Reopen, Delete, Add user, Remove user, Rename, Set priority (low/normal/high/urgent), Transfer, Request closure, Lock/Unlock.
- Close flow: transcript generated by fetching messages via REST (paginated), saved as HTML + text in MongoDB, posted to log channel, DM'd to opener.
- Auto-close inactive tickets (configurable days, warning first), auto-delete closed tickets after N hours, optional archive to closed-tickets category.
- Staff features: ticket stats per staff member, canned responses, internal staff notes (ephemeral), ticket blacklist, claim-only replies option.
- Feedback: on close, user rates 1-5 stars via buttons plus optional comment modal.
- AI extras: ticket summary on close, suggested reply drafts, auto-answer from knowledge base BEFORE ticket created.

## 2. AUTOMOD SUITE (MEE6 / Dyno / Sapphire style)
- Rules (each with enabled flag, action, exempt roles/channels, custom message, and strike points): spam, duplicate messages, caps, emoji spam, mass mentions, zalgo/unicode abuse, invite links, link filter, banned words and regex (with leetspeak normalization), attachment spam, newlines spam, phishing/scam link detection, fake-nitro scam patterns, NSFW image flagging.
- Actions: delete, warn, timeout, kick, ban, add strike points, send to mod-review queue, DM the user, log.
- Strike system: points decay over time, thresholds trigger escalating punishments.
- Use Discord's native AutoMod API rules where possible, and use the worker only for rules Discord can't do.
- Raid protection: join-rate detection, account-age and no-avatar checks, auto-lockdown.

## 3. MODERATION EXTRAS
- Mod notes on users, case search/filters, case edit, bulk actions, softban, temp roles, sticky roles/role persistence, jail/mute role fallback, ban appeals via DM modal -> staff review channel.

## 4. LOGGING (Carl-bot / Sapphire style)
- Separate configurable log channels per category: messages, members, roles, channels, voice, server settings, invites, bans/unbans, emoji/sticker, threads, moderation actions, ticket actions.
- Message snapshot cache with short TTL to log deleted/edited content; opt-in per guild.

## 5. ROLE TOOLS
- Reaction/button/select-menu role panels with modes: normal, unique, verify, drop, max N roles, required role, timed roles, role cooldown.
- Auto-roles on join (with delay), role on level, role on birthday, voice roles, role sync, /role all|humans|bots mass assignment.

## 6. INVITES & GROWTH
- Invite tracking (who invited whom, uses, fake/left/rejoined counts), /invites [user], invite leaderboard, rewards roles at N invites.
- Join gate options: minimum account age, require verification, block disposable-looking names.
- Member milestones announcements, server growth analytics.

## 7. UTILITIES & ENGAGEMENT
- Custom commands/tags with variables and conditions, per-command cooldowns/permissions/channels, auto-responders, timers/scheduled messages, sticky messages, embed builder, announcement auto-publish, auto-thread creation, auto-react, auto-delete, AFK system, counting game, bump/reminder helper, confession/anonymous-submission channel, trivia/word-game, translation context-menu, server/user/role info commands.
- Voice: temp voice channels (join-to-create, owner controls panel).
- Social alerts: Twitch, YouTube, RSS, Bluesky, Reddit, Kick, GitHub releases.

## 8. AI "SERVER BRAIN" FEATURES
- /ai summarize <channel|thread> [timeframe], daily/weekly server digest, server health report, suggested cleanup actions, channel topic and description generator, rules generator, announcement drafter, FAQ builder, AI persona chat in a chosen channel.
- Every AI feature: per-guild credit metering, a hard daily cap, content filter.

## 9. COMMAND & PERMISSION CONTROL
- Per-command and per-module settings: enable/disable, allowed/denied roles and channels, cooldowns, ephemeral-by-default toggle, custom command names/aliases, language per guild.

## 10. DASHBOARD ADDITIONS
- Module marketplace-style page with toggles and "Pro" badges, setup wizard per module, live embed previews, search across settings, activity feed, usage meters.
